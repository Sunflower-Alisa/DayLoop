# User Cases

> 本项目是一套面向个人求职场景的 AI Agent 系统。
>
> 核心目标：围绕「行业信息 → 招聘机会 → JD分析 → 能力Gap → 面试知识 → 模拟面试」建立完整的 AI 求职辅助闭环，帮助用户持续发现机会、判断岗位、分析自身能力、准备面试，并通过持续反馈提升求职竞争力。

---

# UC01 自动任务->AI行业信息收集-DayLoop首页展示

## 1. 场景描述

每天早上，Agent自动收集过去24小时内 AI 行业的重要动态，帮助我快速了解 AI 行业发生了什么变化。

重点关注：
* 字节跳动
* 阿里巴巴
* 腾讯
* Anthropic
* GitHub

重点关注内容：
* 新模型发布
* AI 技术突破
* AI 产品发布
* AI Agent 相关进展
* 开源项目
* 重要项目更新
* 公司 AI 相关动态
* 值得关注的行业事件

## 2. 用户目标

我不希望每天手动浏览大量新闻、技术文章、GitHub 项目和公司动态。

Agent需要帮我：
1. 自动收集信息
2. 过滤低价值信息
3. 去除重复内容
4. 判断信息重要程度
5. 总结核心内容
6. 判断与我的职业发展是否相关
7. 推荐值得进一步关注的内容

## 3. 输入

* 时间范围：过去24小时
* 关注公司：字节、阿里、腾讯、Anthropic
* 关注平台：GitHub
* 关注方向：
  * AI Agent
  * LLM
  * RAG
  * AI应用
  * AI产品
  * AI工程化

## 4. Agent任务

1. 确定搜索范围
2. 搜索相关信息
3. 获取网页、GitHub等来源的内容
4. 对信息进行去重
5. 判断信息与关注方向的相关性
6. 对信息进行分类
7. 判断重要程度
8. 生成摘要
9. 分析信息价值
10. 生成每日 AI 行业日报

## 5. 输出

### AI行业日报

#### 重要动态

每条信息包含：
* 标题
* 来源
* 发布时间
* 核心内容
* 为什么重要
* 对 AI 行业的影响
* 与我的职业发展的相关性
* 原始来源

#### 重点关注

按照重要程度分类：
* ⭐⭐⭐ 高优先级
* ⭐⭐ 中优先级
* ⭐ 低优先级

并说明推荐关注原因。

## 6. 验收标准

* 能获取过去24小时的重要信息
* 能过滤明显无关信息
* 能识别重复事件
* 每条信息具有明确来源
* 能对信息进行分类和排序
* 能生成结构化日报
* 能判断信息与个人职业方向的相关性

1. 自动发现新增岗位

# UC04 Chat/Profile->技能Gap分析

## 1. 场景描述

根据我的个人简历、工作经验、技能情况，与目标岗位和招聘JD进行对比，分析我的优势和能力差距。

## 2. 用户目标

我不仅需要知道：

> 「这个岗位适不适合我？」

还需要知道：

> 「如果我想获得这个岗位，我还缺什么？」

Agent需要帮助我建立持续更新的个人能力画像。

## 3. 输入

### 个人信息

* 个人简历
* 工作经历
* 项目经历
* 技能
* 学习经历
* AI Agent项目经历
* GitHub项目

### 岗位信息

* 目标岗位
* 招聘JD
* 岗位要求

## 4. Agent任务

1. 解析个人简历
2. 建立个人技能画像
3. 解析目标岗位
4. 提取岗位能力要求
5. 对比个人能力与岗位要求
6. 识别已有能力
7. 识别能力差距
8. 判断Gap的重要程度
9. 给出补齐建议
10. 形成个人能力成长路线

## 5. Gap分类

### 已掌握

与岗位要求匹配的能力。

### 部分掌握

具备基础能力，但距离岗位要求仍有差距。

### 未掌握

岗位要求中目前没有相关经验的能力。

### 隐性能力Gap

JD没有明确写出，但根据岗位职责推断出的能力要求。

## 6. 输出

### 岗位匹配度

例如：

> 综合匹配度：78%

### 优势

* 已有能力
* 项目经验
* 技术经验
* 行业经验

### Gap

| 能力        | 当前水平 | 岗位要求 | Gap程度 |
| --------- | ---- | ---- | ----- |
| Python    | 熟悉   | 熟练   | 小     |
| RAG       | 项目经验 | 生产经验 | 中     |
| Agent     | 项目经验 | 生产经验 | 中     |
| LangGraph | 学习阶段 | 熟练   | 大     |

### 优先级

* P0：必须补齐
* P1：建议补齐
* P2：长期提升

### 学习建议

针对每个Gap给出：

* 学习内容
* 实践项目
* 推荐资料
* 预计学习优先级

## 7. 验收标准

* 能准确建立个人技能画像
* 能识别岗位要求与个人能力之间的差异
* 能区分大Gap和小Gap
* 能给出明确的优先级
* 能根据多个JD发现重复出现的能力Gap
* 能形成长期能力成长方向

# UC06 Chat->AI模拟面试

## 1. 场景描述

Agent基于面试知识库、实时搜索到的相关知识以及我的个人技能画像，模拟真实面试官与我进行面试。

面试过程中，Agent根据我的回答动态调整后续问题，而不是按照固定题库依次提问。

## 2. 用户目标

希望通过模拟面试：

* 发现知识盲区
* 发现表达问题
* 发现技术理解不足
* 训练面试表达能力
* 训练临场反应能力
* 提前发现真实面试中的风险

最终达到：

> 像真正的面试官一样进行连续、动态、深入的面试。

## 3. 输入

### 个人信息

* 个人简历
* 工作经历
* 项目经历
* 技能画像
* 技能Gap

### 岗位信息

* 目标岗位
* JD
* 公司信息
* 岗位要求

### 知识来源

* 面试知识库
* 历史面试题
* RAG知识库
* LLM实时搜索结果

## 4. 面试流程

### 第一阶段：确定面试范围

Agent根据：

* 目标岗位
* JD
* 个人经历
* 技能Gap
* 面试知识库

生成面试计划。

### 第二阶段：开始面试

Agent提出第一个问题。

用户回答。

### 第三阶段：分析回答

Agent分析：

* 回答是否正确
* 是否完整
* 技术理解是否准确
* 是否存在逻辑问题
* 是否存在知识盲区
* 是否存在表达问题
* 是否与个人经历匹配

### 第四阶段：动态追问

根据用户回答动态生成下一问题。

例如：

> Q1：什么是RAG？

用户回答。

Agent发现用户提到了：

> Embedding + Vector DB

那么继续追问：

> 为什么仅使用Vector Search可能无法得到最准确的结果？你会如何优化？

继续根据回答：

> 为什么需要Rerank？

再继续：

> 如果Rerank之后Context仍然很长，你会怎么处理？

形成连续的深度追问。

### 第五阶段：纠正与反馈

Agent指出：

* 正确部分
* 错误部分
* 缺失部分
* 表达问题
* 更好的回答方式

并给出参考答案。

### 第六阶段：面试总结

面试结束后生成：

* 总体评分
* 技术能力评分
* 岗位匹配度
* 表达能力
* 逻辑能力
* 知识掌握程度
* 高频错误
* 知识Gap
* 建议复习内容
* 下一次模拟面试重点

## 5. 面试模式

### 技术面

重点考察：

* LLM
* RAG
* Agent
* Python
* AI工程化
* 系统设计

### AI产品面

重点考察：

* 用户需求
* AI产品设计
* Agent产品设计
* AI产品评测
* 产品思维

### FDE面

重点考察：

* 客户需求分析
* 技术方案设计
* 快速开发
* 问题解决
* 客户沟通
* AI应用落地

### 综合面

模拟真实面试流程，综合考察：

* 项目经历
* 技术能力
* 产品能力
* 场景分析
* 沟通能力
* 解决问题能力

## 6. 核心要求

模拟面试不能只是：

> 题库 → 随机抽题 → 用户回答 → 给答案

而应该具备：

```text
    岗位
    ↓
    JD
    ↓
    个人能力画像
    ↓
    技能Gap
    ↓
    面试知识库
    ↓
    生成面试策略
    ↓
    提问
    ↓
    用户回答
    ↓
    分析回答
    ↓
    发现薄弱点
    ↓
    动态追问
    ↓
    再次分析
    ↓
    持续深入
    ↓
    面试总结
    ↓
    更新个人能力画像
```

## 7. 验收标准

* 能根据岗位生成面试计划
* 能结合个人经历生成问题
* 能结合知识库生成问题
* 能根据用户回答动态追问
* 能识别错误和知识盲区
* 能对回答进行评分
* 能给出改进建议
* 能持续深入同一个知识点
* 不按照固定问题列表机械执行
* 面试结束后能够生成完整评估报告
* 面试结果能够反向更新个人技能Gap

# Use Case整体闭环

六个Use Case最终形成完整的AI求职闭环：

```text
                    AI求职 Agent
                         │
        ┌────────────────┼────────────────┐
        │                │                │
     行业认知           求职发现          面试准备
        │                │                │
      UC01             UC02             UC05
        │                │                │
        │              UC03              UC06
        │                │                │
        └────────────── UC04 ─────────────┘
                         │
                    技能Gap分析
                         │
                    反馈到个人画像
                         │
                         └──────→ 下一轮求职
```

## 核心数据流

```text
    行业信息
    ↓
    AI行业认知
    ↓
    招聘信息
    ↓
```

> **Personal AI Job Agent**
