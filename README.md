# DayLoop — 每日计划与复盘工具

DayLoop 是一款轻量级的个人每日管理系统，围绕 **「计划 → 执行 → 记录 → 复盘 → 优化」** 循环设计，帮你把一天安排得明明白白。

## 它能解决什么问题？

### ❓ 你是不是也有这些问题？

- 早上到工位 / 坐到书桌前，随手打开一个网页——**然后呢？今天要做什么？**
- 手边一堆便利贴、几个待办 App、备忘录里零散的笔记——**信息散落得到处都是**
- 每天忙忙碌碌，到晚上回忆：**今天到底干了什么？好像什么都想不起来**
- 想坚持学点东西、看点书，但 **总是三天打鱼两天晒网**，没有持续的动力

### ✅ DayLoop 的解法

**一个工具覆盖完整闭环：**

| 环节 | DayLoop 做什么 |
|------|---------------|
| 📋 **计划** | 每天早上打开「今日计划」，把要做的事列出来，排好时间和优先级 |
| ⏱️ **执行** | 任务状态跟踪（待开始→进行中→已完成），记录实际耗时，做完标记完成 |
| 📝 **记录** | 完成任务时写下成果、遇到什么坑、收获什么经验；随时记备忘录 |
| 🔁 **复盘** | 晚上打开「每日复盘」，系统自动统计完成率、时间分布，你只需写几句反思 |
| 📈 **优化** | 看统计图表发现规律：什么类型的事完成率高？什么时间段效率好？ |

## 主要功能

| 功能 | 说明 |
|------|------|
| **今日计划** | 按日期管理任务，支持计划内/计划外分类、时间排期、优先级、标签 |
| **完成任务** | 完成任务时弹窗记录成果，支持文字+图片，可选同步到知识库 |
| **每日复盘** | 系统自动生成完成率、时长对比等统计摘要，支持手动书写反思内容 |
| **循环任务** | 设置每日/每周模板，每天 09:00 自动生成次日任务，无需重复手动添加 |
| **成果墙** | 按分类查看所有已完成任务的成果记录，回顾成长轨迹 |
| **备忘录** | 支持 Markdown 内容和图片的富文本笔记，可关联到任务，支持分类和搜索 |
| **问题库** | 记录学习或工作中遇到的问题，标注答案来源（自答/AI/网络），关联任务 |
| **历史浏览** | 按日期查看任意一天的任务和复盘记录 |
| **统计看板** | 可视化展示完成率、周趋势、任务分布等统计信息 |
| **时长统计** | 统计看板支持计划时长与实际耗时统计，按分钟汇总并格式化为 Xh Ym 展示 |
| **Obsidian 同步** | 将备忘录、复盘、任务成果自动同步到本地 Obsidian 知识库，图片自动复制到库中并重写路径，形成永久知识沉淀 |
| **PWA 支持** | 可安装到手机 / 电脑桌面，体验类原生应用；支持通知提醒 |
| **数据导出** | 一键导出全部数据为 JSON |

## 技术栈

| 层 | 技术 |
|---|------|
| 前端 | Vue 3 + TypeScript + Vite + Vue Router 4 |
| 后端（可选） | Node.js (Express.js) **或** .NET 10 (ASP.NET Core) |
| 数据库 | SQLite（单文件，无需安装数据库服务） |
| 原生包装 | Capacitor（Android / iOS） |
| 部署 | Docker / 直接运行 |

两种后端功能完全一致，共享同一 SQLite 数据库，按偏好任选其一即可。

## 快速开始

### 前置条件
- Node.js 18+（两种后端都需要）
- .NET 10 SDK（仅在使用 .NET 后端时需要）

### 方式一：Node.js 后端（默认）

```bash
# 1. 安装依赖
cd backend && npm install
cd ../frontend && npm install

# 2. 构建前端
cd ../frontend && npm run build

# 3. 启动（默认端口 3001）
cd ../backend && npm start
# 浏览器打开 http://localhost:3001
```

### 方式二：.NET 后端

```bash
# 1. 安装前端依赖并构建
cd frontend-dotnet && npm install && npm run build

# 2. 启动（默认端口 5000）
cd ../backend-dotnet && dotnet run
# 浏览器打开 http://localhost:5000
```

### 方式三：Docker

```bash
docker compose up -d
# 浏览器打开 http://localhost:3001
```

### 方式四：Windows 启动脚本

```bash
# 交互式菜单，支持本地/LAN/公网/开发模式
start.cmd
```

## 使用指南

### 第一步：注册账号
打开应用 → 注册账号（用户名+密码）→ 自动登录进入首页

### 第二步：创建今日计划
首页点击「今日计划」或导航到计划页面 → 点击「添加任务」→ 输入标题、时间、分类 → 保存

### 第三步：执行与记录
- 任务卡片上点击**状态切换**：待开始 → 进行中 → 已完成
- 标记完成时弹出**成果记录**窗口：写下收获，可插入图片
- 随时在「备忘录」中记录灵感和笔记

### 第四步：每日复盘
导航到「复盘」→ 系统自动生成当日统计摘要 → 在下方撰写反思内容 → 保存

### 第五步：设置循环任务（可选）
导航到「循环模板」→ 添加模板（设置标题、时间、分类、重复类型）→ 每天 09:00 自动生成

### 第六步：连接 Obsidian 知识库（可选）
个人资料页 → 配置 Obsidian Vault 路径 → 备忘录、复盘、成果自动同步到本地 Markdown 文件

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | 3001 / 5000 | 服务端口 |
| `NODE_ENV` | development | 设为 `production` 以提供前端构建产物 |
| `TUNNEL` | false | 设为 `true` 启用 ngrok 公网隧道 |
| `JWT_SECRET` | 内置默认值 | JWT 签名密钥 |
| `DB_PATH` | backend/data/dayloop.db | 数据库路径 |
| `DAYLOOP_DB_PATH` | 同上 | .NET 后端数据库路径 |
